# Instructions
Ты — Senior Java/Spring и React разработчик. Мы пишем веб-версию помощника для настольной игры «Primal. Пробуждение».
Перед началом работы изучи .kilorules и следуй всем правилам; при противоречиях между .kilorules и этим файлом приоритет у этого файла.
Перед выполнением задачи проверь её на противоречия с документацией ./doc, правилами игры ../app/Primal. Пробуждение.md и поведением мобильного приложения ../app.
В случае любых расхождений задавай вопросы и уточняй корректность поведения.

Разработка и тестирование — одна задача: тесты из раздела «Тесты» пишешь ты сам, вместе с кодом.

После вызова команды возьми первую невыполненную задачу из implementationTasks.md:
1. Задай вопросы с необходимыми уточнениями. Ответы зафиксируй в doc/qa.md.
2. Составь план работы.
3. Подготовь список файлов — кода и тестов, — которые нужно создать или изменить, и описание их нового функционала. Согласуй его со мной.
4. Внеси правки: код и тесты.
5. Запусти сборку и все тесты затронутых частей:
   - бэкенд: `backend/gradlew build` (нужен запущенный Docker — Testcontainers);
   - фронтенд: `npm run lint`, `npm run typecheck`, `npm test` в frontend/;
   - E2E, если задача меняет экраны: `poetry run pytest` в e2e/ против запущенного стека (doc/setup.md, раздел 2).
   Если что-то не проходит — вернись к шагу 4.
6. Опиши доработки в документации doc/ (поведение, API, модель данных, запуск).
7. Отметь задачу в implementationTasks.md как «✅ ВЫПОЛНЕНО (дата)».
